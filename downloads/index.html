Downloads

Native builds for macOS, Windows and Linux. The app carries its own engine, so there is no runtime, no server and no other package to install first.

One line, macOS

curl -fsSL https://ptype.app/install | sh

Installs the latest build into Applications and clears the macOS warning. On Homebrew, brew install --cask ptype. Windows and Linux are below.

What you need.

macOS
12 or newer, on Apple silicon or Intel.
Windows
10 or newer, on x64.
Linux
x64 or arm64, packaged for Debian based systems.

Motif does not ship a model. On first launch it picks one for you, including free cloud presets that need no card, or you can point it at Ollama on your own machine.

After the install.

There is no account and no sign in. The app opens on a conversation, and a project only exists once you ask for work. Everything it writes lands on your disk, in ~/ptype/.
