Motif
the loop

A chat that ships.

Build a small CLI that reads my bank CSVs and prints a monthly spending report. Keep it local.
01

It files the work.

Say what you want in one sentence. Pip creates the project, breaks it into a handful of requests, and gives every one a file or folder to land in.

Keep going. Don’t stop until the tests pass.
02

Then it builds it.

An agent works inside a real folder on your machine: writing files, running the checks, and fixing what fails. You see each step as it happens.

Commit it.
03

And keeps it.

A tester has to pass before the work is done. Then it’s committed to real git history, so the next request starts from something that exists.

memory

Locally served, locally remembered.

Pip’s memory is a locally stored vector database, not a chat log. Notes are embedded on your machine and kept as markdown files, and the index reindexes itself automatically whenever they change — so recall stays current and private.
