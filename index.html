What it is

A console, an engine, and an agent.

The console

One place to run it all

Projects, requests, providers, models, plugins and a live timeline of every change — a single desktop app. No browser tabs, no cloud account.

The engine

Local, and it actually does work

A self-contained engine holding your project ledger, real git history and voice — with an MCP endpoint so other agents can drive it.

The agent

Writes files. Tests them. Commits.

Point it at a task and it works inside a folder on your disk: writes real files, runs the checks, and a tester has to pass before it’s done.

The agent

Tell it to do something. It gets done.

The model drives real tools in a workspace on your machine: it writes files, reads them back, runs allowlisted commands, and a tester must pass before the task is finished. Then it commits — real history, not a claim. Every step shows up as it happens.
