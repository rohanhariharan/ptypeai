Getting started

Download a native build from ptype.app/downloads — macOS (Apple silicon & Intel) or Windows. Open it like any app; there's no account, no telemetry, and no cloud.

  • ptype ships a self-contained engine — you don't need Node, Python, or anything else installed.
  • On first launch, tell ptype where the model should run (Ollama, an OpenAI-compatible endpoint, or Anthropic). If Ollama is already running, it just works.
  • Then make a project: say what you want and ptype files it into requests. Run a request and a real agent writes files, tests them, and commits to git — inside a folder on your disk.

Your files, agents and history never leave the machine. Everything you run is visible in the Timeline.

Models & MCP

ptype speaks three model backends — configure them in Settings → Models:

  • Ollama — local, the default (http://localhost:11434).
  • OpenAI-compatible — any base URL plus a key.
  • Anthropic — a Claude key, used directly.

Each Pip can run a different model and job, so one team can build, test and plan with whatever fits.

ptype also exposes an MCP server (JSON-RPC 2.0 over HTTP) so the agents you already use can drive it — opencode, Claude Code, Codex, or anything that speaks MCP:

// add to your MCP client config
{
  "mcpServers": {
    "ptype": { "url": "http://localhost:8787/mcp" }
  }
}

Available tools:

  • list_projects, create_project
  • list_requests, create_request
  • run_task — run the agent on a request
  • timeline, ask, diagnostics, get_provider

Tachyon & Interlink

Tachyon is the cross-agent view: every agent, one ledger. Agents from the tools you use connect over MCP and report into the same ledger your local pips and background runs write to.

  • Providers — each connected agent. Only vendors actually connected to the ledger show as active; nothing is inferred.
  • Working groups — when a run is deputed, the pips it staffs become that provider's group, shown hanging off the provider.
  • Handoffs — work moving from one provider to another.

The Table is a live key/value topic tree over the ledger — the door for humans and the device, alongside the MCP verbs for agents. Read it over HTTP and watch it on the event stream:

GET /api/table                 → { cursor, topics[] }
GET /api/table?prefix=/tachyon/agents
GET /api/table/tachyon/agents/opencode/calls
GET /api/events                → SSE stream (watch)

Interlink is the semantics under it: the ledger is the source of truth, tasks and runs are projections of it, events are append-only and resume by cursor, and MCP is the transport. Local-first — the engine keeps working offline.

Plugins, presets & billing

  • Pips — standing agents with a name, colour, model and job. You depute them per run; up to 5 on Base.
  • Presets — reusable job prompts you assign to a Pip (builder, tester, planner…).
  • Plugins — install and enable plugins that add working guidance to your workers, across build, quality, docs, git, data, integration and product.

ptype is free. Plugins and presets are part of the app — no account, no plan, no license key.
