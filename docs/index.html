Install

There is a one line installer, and there are plain builds for each platform. The installer clears the macOS warning for you, so there is no trip to System Settings.

curl -fsSL https://ptype.app/install | sh

On macOS you can also use Homebrew:

brew install --cask ptype

Builds exist for macOS on Intel and Apple silicon, Windows x64, and Linux on x64 and arm64. The app carries its own engine, so there is no Node, Python or server to install first.

First run

On first launch Typecode starts with a model on this machine and shows what it found. If there is no local model, it offers a free hosted one without a card. Local is the default; a hosted provider only sees the prompts you send it.

Nothing is created until you ask for work. Opening the app does not make a project, and talking to it does not either.

Projects and requests

A request is a sentence you write. Typecode files it into a project, breaks it into steps, and starts a run. Every request needs somewhere to put the result, so it ends in a file or a folder inside the project.

  • Every step is visible as it happens, with the files it touched.
  • A failed run can be retried from where it stopped.
  • The sidebar keeps the open requests for the project you are in.

Verification

A written file is not a finished one. Before a step counts as done, Typecode runs the checks the project supports: compileall and pytest for Python, node --check for JavaScript, language server errors for everything else, and the final verification gate.

Work that fails those checks is not committed and is not copied into the project. Only a step that passes becomes a commit.

Agents and background work

Work can keep running outside the current conversation. Background jobs continue while you use other parts of the app, and the local agent mesh can hand tasks between tools on this machine.

  • One control pauses or stops everything that is running.
  • You can start opencode, Claude Code or Codex on a project from inside Typecode.
  • Specialist plugins add working guidance and capabilities to the agent.

Skills

Skills are reusable working instructions. Typecode ships with a frontend skill (layout, type, motion, accessibility and visual QA) and a backend skill (API contracts, validation, data, auth, migrations, tests and observability). The worker loads the matching skill for a task; either surface can load another withload_skill.

  • Add one in the Skills tab.
  • Drop a markdown file with frontmatter into ~/.config/ptype/skills/.
  • Use POST /api/skills with a name, description, triggers and body.

Models

Any of these work, and you can switch between them per conversation:

  • Ollama, running on your machine.
  • Any endpoint that speaks the OpenAI API.
  • Anthropic.

A thinking depth slider runs from fast and cheap to slow and thorough. The context dial shows how much room is left before the model starts forgetting the top of the conversation.

Reply modes

Talk answers the question. Code works in the project. Plan produces the steps without running them. Explain walks through what it found. Research writes a sourced report to a file.

Memory and search

Memory is a set of markdown files you can open and read. Notes are scoped to the whole machine, to one project, or to one agent. Each agent gets a level: read, read and write, or delete as well.

Local search returns passages with the path and line they came from, so a claim can be checked rather than trusted. Web search and academic search go through OpenAlex and Crossref, and both need no key.

Research mode writes one report with every source at the bottom, by default into ~/ptype/research/. Reports can be sent to an Obsidian vault, or created as a Notion page with a local integration token.

Tachyon

Tachyon is the mesh under a project. Every worker is a node on it, so a step can declare what it depends on and release the moment the step before it lands. The mesh view shows what each agent is doing and what moved between them.

Agents coordinate over the wire, a small command language, so handing off work does not cost a model call.

typecode.local

Started from inside Typecode, typecode.local puts a guest room on your own network. A colleague opens it in a browser, enters a six character code, and talks to an agent running on your machine.

  • The first join needs your approval, and you can revoke anyone after that.
  • The code rotates on demand.
  • Guests get the conversation and the agent’s live actions, nothing else.
  • No filesystem tools, no project files, no engine routes.

MCP and the API

The engine listens on your machine only. There is no cloud in the path.

Base URL   http://localhost:8787
Health     http://localhost:8787/api/health
MCP        http://localhost:8787/mcp   (JSON-RPC 2.0 over HTTP)

To let another agent drive Typecode, point its MCP client at the endpoint:

{"mcpServers":{"ptype":{"url":"http://localhost:8787/mcp"}}}

Typecode is also an MCP client, so outside tools and data sources can be attached to it. The Table is a live key and value feed for scripts, dashboards and devices.

Data lives in ~/ptype/ptype.db, and each project is a folder under ~/ptype/.

Security

There is no account and no telemetry. Nothing leaves the machine unless you send it somewhere.

  • Your model provider receives the prompts you send it.
  • Web and academic search send the query you typed.
  • A report leaves the machine when you export it to Notion.

The local API has no authentication and allows any origin, because it is a trusted service on your own machine. Keep port 8787 off the network. If you need to reach Typecode from outside, use the sharing controls rather than opening the port.

Plans and licence

Typecode is free for one person on one machine, and everything that runs locally is included. Spark at $5 a month and Pro at $20 a month are in the build, and neither can be bought yet. Team and Enterprise are planned. If you already have a licence key, paste it in Settings → Licence key; it is checked on your machine, with no account and no phone home.

The free download is licensed for personal use only. Using it at work needs a separate licence, which is issued by hand until a checkout exists. Write to hello@ptype.app for that.

The current plans are on the pricing page, and the full licence is on the legal page.
