Typecode

The all in one agentic harness and taskmaster from ptype AI. It turns a sentence into finished work: reads the project, writes the files, checks what it produced and commits what passes. The model and the files stay on your machine.

What it does

  • Projects and requests

    Say what you want. Typecode files it into a project and breaks it into steps.

  • A verification gate

    Nothing counts as finished until a test actually passes.

  • Real history

    Every step that passes is committed to version control.

  • Checks that mean something

    Catches real errors in five languages before calling the work done.

  • Workbench

    File tree, editor, terminal and search in the same window.

  • Pips

    Five standing workers, each with a model and a job.

  • Memory

    Decisions saved as markdown files you can open and read.

  • Your own model

    Ollama on your machine, any OpenAI compatible endpoint, or Anthropic. Local is the default; a hosted model is opt-in.

Tachyon

The mesh under every project. Each worker is a node, so a task can wait for the step before it and then hand off by itself. You watch the whole thing move instead of wiring the sequence up by hand.

  • Mesh view

    Every agent in the project, what it is doing, and what moved between them.

  • Interlink

    A task declares what it depends on. It waits, then releases the moment the step before it lands.

  • Wire protocol

    A small command language, so agents coordinate without spending a model call to say hello.

typecode.local

A guest opens typecode.local on the office Wi-Fi, enters a six character code, and talks to the agent running on your machine. No account, no cloud, and nothing leaves the network.

  • Chat only

    No filesystem tools, no project files, nothing but the conversation and the work in front of it.

  • You hold the door

    The first join needs your approval. After that you can revoke anyone and rotate the code whenever you like.

  • Your model does the work

    Guests spend tokens on your machine, not in our account. We host nothing.
