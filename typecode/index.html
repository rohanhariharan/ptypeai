The check is the finish line

A run is not done because the model stopped. The tests, the language server and the visual checks decide. If a check fails, the agent sees the failure, fixes it and runs it again.

Only then does the step commit. That commit is real git history you can inspect, keep or rewind.

Plans finish

A run ends when the work is done, not when a step counter runs out. A plan files each step as a request, runs them in order, and keeps working until every one is verified — or you stop it.

The checks are the endpoint: tests, language-server diagnostics, and the page at 390 and 1440.

Surface

Surface is a tab the agent opens for the work: code, markdown, a terminal or a browser. It is the file, not a screenshot. Markdown is the editor — click and type, and the agent's writes land live with a caret on the words it changed.

Code saves back to the same file. Select a paragraph and ask for a rewrite in place. When the run is done, the surface is already the place you read it.

Connectors

Finished and failed runs can post to Slack, Discord or any HTTPS webhook. The agent can send a summary when you ask it to.

Email works both ways through your own server: send over SMTP, and read a Gmail mailbox over IMAP without changing it. Credentials stay on this machine. No bot account, no relay.

What it does

  • A plan, not a prompt

    Say what you want. Typecode files it into a project, breaks the work into requests and keeps the order.

  • Open a repository

    Point it at a real checkout. It works in an isolated worktree and carries the repo's own test and build commands.

  • A verification gate

    Nothing counts as done until the tests, the language server and the visual checks pass.

  • Real history

    Every passing step is committed to real git history. Every message can be rewound to.

  • Workbench

    File tree, editor, terminal and search in the same window as the agent.

  • Memory

    Decisions saved as markdown files you can open, read and edit.

  • Background runs

    Start a chat that keeps working while you do something else. It runs detached and keeps its own transcript.

  • Skills

    Reusable working instructions, built in or written by you. Project rules travel with the code.

  • Your own model

    Ollama on this machine, any OpenAI-compatible endpoint, or Anthropic. Local is the default; hosted is opt-in.

Tachyon

Every agent is a node. A request can wait for the step before it and release the moment it lands. You watch the mesh move instead of wiring the sequence up by hand.

  • Mesh view

    Every agent in the project, what it is doing, and what moved between them.

  • Interlink

    A task declares what it depends on. It waits, then releases the moment the step before it lands.

  • Wire protocol

    A small command language, so agents coordinate without spending a model call to say hello.

On your machine

The engine, the model, the files and the record stay local. Ollama on this machine, any OpenAI-compatible endpoint, or Anthropic — one choice per worker.

  • No account

    Install it and work. There is no login and no telemetry by default.

  • Your credentials

    Slack, Discord, webhooks and a read-only mailbox. It sends a summary only when you ask.

  • typecode.local

    A guest on your Wi-Fi joins with a six-character code. Chat only, approved by you, spending your model.
